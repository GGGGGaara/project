# 成果分类导航

本目录用于按用途查找成果；源代码、实验数据及论文仍位于原目录。

| 分类 | 入口 |
|---|---|
| 研究说明、阶段结论 | [01_研究说明](01_研究说明/README.md) |
| 仿真代码、测试与脚本 | [02_仿真代码](02_仿真代码/README.md) |
| 实验数据、图、失败诊断 | [03_实验结果](03_实验结果/README.md) |
| 文献、查新、译文 | [04_文献与查新](04_文献与查新/README.md) |
| 已探索但非当前主线的方向 | [05_历史探索](05_历史探索/README.md) |
| 运行与轮流交接 | [06_复现与交接](06_复现与交接/README.md) |

- [文件清单.csv](文件清单.csv)：逐文件路径、类别、阶段、用途、大小、SHA256，UTF-8 BOM编码。
- [分类统计.json](分类统计.json)：按目录、阶段和类别统计；注明排除项。
- [整理前文件快照.json](整理前文件快照.json)：本轮整理前的研究文件哈希。
- [整理校验.json](整理校验.json)：旧文件完整性、原包15文件、最新代码哈希及新增文档链接的核对结果。
- [tools/catalog_artifacts.py](tools/catalog_artifacts.py)：重新生成清单和校验，仅扫描与写入导航记录，不运行车辆实验。

清单不是持续自动更新的数据库。在工作区根目录运行 `python 成果导航/tools/catalog_artifacts.py` 可更新。新增了研究顶层目录时，需先在脚本ROOT_ITEMS里加入。`.git`、`__pycache__`和审阅目录中的`python_packages`第三方安装包不作为研究成果列入。
