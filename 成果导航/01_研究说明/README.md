# 01 研究说明与阶段成果

## 当前问题

车辆在乡镇集市等低速混行环境中，需要面对临时占用、横穿加速和停顿。研究重点是车辆能否执行自己的通行、停车和再起步动作，而不是构建社会学解释或仅优化行人预测。

当前使用本地Python仿真、二维运动学车辆和简化纯电动力/制动执行模型。未使用标定实车、CARLA、SUMO或真实集市数据；不把应用场景本身当作创新。

## 可复用成果与尚缺内容

可复用：BEV执行模型、停车参考与跟踪、二维车体几何、场景观测接口、三种更新策略、回放/决策记录和独立验证脚本。

尚缺：经过核查的独立创新、车辆标定、执行状态误差传播、可信停车备选约束、公平的文献算法对照、连续时间安全证据、足够丰富且有来源依据的场景。

下一项任务：比较固定低速、固定安全裕量与执行状态相关停车裕量，检验何时仍能停住、代价多大、何时失败。“加入动力学”“使用电动车”“滚动重规划”“留备份动作”均不能单独声称原创。
