# 集市文献与等待位姿：历史探索

此目录保存集市方向的文献核查和行人通路连通性探针。**当前主线已转向车辆自身运动与执行方案**，见[STV_ED_motion_study](../STV_ED_motion_study/README.md)。

| 文件/目录 | 用途 |
|---|---|
| [乡镇集市文献核查与创新点分析](乡镇集市_文献核查与创新点分析.md) | 定向文献对照和等待位姿候选，查新范围以正文为准 |
| [connectivity_probe.py](connectivity_probe.py) | 等待位置与行人通路连通性最小探针 |
| [inspect_sources.py](inspect_sources.py) | 原文检查辅助脚本，非车辆控制器 |
| `probe` | 连通性探针输出、CSV、汇总和图 |
| `tmp` | 4份本地PDF、文本、局部页图和下载清单 |

这些结果不是BEV动态执行数据，也没有证明等待位姿方法原创。当前保留作相关工作与历史方案，勿与最新72例合并。

本地论文与来源链接见[文献导航](../成果导航/04_文献与查新/README.md)。
