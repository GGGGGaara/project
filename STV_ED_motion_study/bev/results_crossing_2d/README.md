# S04 二维恒速横穿结果

代码：[crossing_2d.py](../crossing_2d.py)；解释：[二维横穿场景联调记录](../二维横穿场景联调记录.md)。

60次执行 = 5个横穿时刻 × 3种BEV条件 × 4种内部策略。nominal、slow_only分别12/15无碰撞完成；stop_wait、candidate分别15/15完成。

本阶段采用固定横向路线、恒速横穿与理想预测；行驶中不重新选择轨迹。不能将15/15解释为处理不确定性的安全证明。

保留逐时刻CSV、决策JSON、参数、图及局部GIF。该阶段的负对照在接触后仍继续积分，没有碰撞动力学；统计时须同时区分完成与无碰撞。S05则在接触后终止，因此不要混用阶段间的完成时间定义。
