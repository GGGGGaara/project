# 观测、预测与实际执行分离后的验证记录

日期：2026年11月3日。研究主线保持为车辆在时变狭窄空间中的可执行运动规划。本阶段是功能验证和失败诊断，尚未形成论文创新结论。

## 1. 本轮完成的工作

新增 `crossing_uncertain.py`，沿用二维矩形车体、固定横向路径、摊位障碍及纯电驱动/复合制动执行模型。将三个层次分开：

1. **实际世界**：横穿对象可以恒速、突然加速或在道路中停顿；真实轨迹仅用于生成已到达的观测和评价实际碰撞。
2. **观测与预测**：每0.5 s接收带时间戳的位置、速度观测。预测器只接收观测快照，进行延迟补偿与恒速外推，不能读取未来行为变化。
3. **车辆执行**：纵向位置/速度跟踪、转向、驱动转矩响应和摩擦制动响应在0.02 s步长下运行。预测安全不自动等于实际执行安全。

滚动策略允许车辆在行驶中重新选择停车参考，停车后等待，再检查是否恢复通行。普通停车候选搜索失败时，执行明确标记为 `emergency_unverified` 的制动尝试。它仍受当前控制器的加速度请求变化率及执行器响应约束，并非经过安全证明的紧急制动模块。

## 2. 实验设置

本轮为72个手工构造用例：4种实际运动 × 3种观测条件 × 2种车辆条件 × 3种策略。不是随机采样交通数据，不能用来估计真实事故概率。

| 实际运动 | 设置 |
|---|---|
| constant17 | 初始横向速度1 m/s，恒速横穿 |
| speedup_early | 初始1 m/s，第9 s变为2 m/s |
| speedup_late | 初始1 m/s，第12 s变为3 m/s |
| pause_in_road | 初始1 m/s，第13.5 s在y=-0.5 m处停顿，第18 s恢复1 m/s |

速度瞬间切换是压力测试脚本，没有标定行人加速度，也没有代表老年人、儿童或乡镇集市人群的统计分布。场景当前只抽象出集市通行中的突发占用变化，尚不能代表完整集市交通。

| 观测条件 | 延迟 | 位置偏差 | 速度偏差 |
|---|---:|---:|---:|
| ideal | 0 s | 0 m | 0 m/s |
| delay_positive_bias | 0.4 s | +0.1 m | +0.12 m/s |
| delay_negative_bias | 0.4 s | -0.1 m | -0.12 m/s |

这些是固定有符号偏差，不是随机噪声。“正/负”仅描述数值符号，不代表在所有情况下都更乐观或更保守。当前自车位姿被视为已知，无漏检、遮挡及误检。

车辆条件为常温25℃/摩擦响应时间常数0.18 s，以及低温-5℃/时间常数0.35 s；初始SOC均为0.55。所有参数均为通用假设，未经具体车型标定。电机驱动、再生制动和摩擦制动共同决定执行结果；再生能力受限不等于总制动能力丧失。

三个策略共用车辆、世界和观测接口：

- `frozen`：仅使用初始恒速预测，后续收到观测也不更新预测。
- `refresh_hold`：更新预测，但仅在初始决策及停车等待时采取新的行动。
- `rolling`：在前进模式中每0.5 s检查新预测，必要时改为停车；停车后检查恢复通行。停车和制动尝试过程中尚不重新优化轨迹。

这些是用于隔离更新机制的内部对照，尚不构成与成熟规划算法的公平基准比较。

## 3. 最终结果

| 策略 | 无碰撞完成 | 碰撞终止 | 超时/无进展 | 触发未验证制动回退的用例 |
|---|---:|---:|---:|---:|
| frozen | 8/24 | 16/24 | 0/24 | 0 |
| refresh_hold | 10/24 | 14/24 | 0/24 | 0 |
| rolling | 22/24 | 2/24 | 0/24 | 10 |

“完成”需要到达终点并停车，且整个回放未出现车体接触、摊位碰撞或驶出道路。碰撞后立即终止，不模拟碰撞动力学；失败用例的 `finish_s` 为null。

只统计成功用例时，平均完成时间分别为30.71、30.83、33.33 s。由于三组成功集合不同，不能据此直接比较通行效率；后续应使用同一成功子集或包含失败惩罚的预先确定指标。

结果支持的有限结论是：在这些构造用例中，行驶时更新能够处理部分预测变化，但该实现仍有失败。不能声称普遍安全、显著优于现有研究，或已发现独立创新。

## 4. 保留的两次失败

失败用例均为 `speedup_late + delay_negative_bias + rolling`，分别对应常温与低温慢响应车辆条件。两者均在13.42 s接触横穿对象。

| 诊断量 | 数值 |
|---|---:|
| 实际横穿速度变化时刻 | 12.00 s |
| 首次触发制动尝试时刻 | 12.50 s |
| 触发时车速 | 2.8175 m/s |
| 触发时实际加速度 | +0.1703 m/s² |
| 触发时电机转矩 | +19.40 N·m |
| 触发时摩擦制动力容量状态 | 约0 N |
| 车头至横穿圆形对象纵向带边界的距离 | 2.3314 m |
| 普通停车参考拒绝原因 | reference_not_found |

触发前仍处于轻微驱动状态，不能假定收到减速决策后立即具有恒定制动力。剩余距离、当前驱动/制动状态、请求变化率和执行延迟需要一并检查。

这里的距离是纵向几何诊断量，不是完整二维避碰裕量。用v²/(2×2.5)得到的理想停车距离约1.588 m，忽略了上述因素及横穿几何，也不能直接证明能停住或不能停住。指定七次多项式参考搜索失败，更不能证明其他轨迹不存在。

两种车辆条件结果相同，因此不能把这两次失败直接归因于低温、再生制动衰减或新能源汽车特性。当前首先暴露的是反应式策略与未验证制动回退的局限。

## 5. 验证与计时问题修复

6项单元测试通过，覆盖观测因果性、延迟补偿、不读取未到达变化、恒速预测一致性、停顿积分连续性、固定偏差及观测时刻边界行为。

独立验证器检查了全部72条回放中的实际横穿位置、延迟和偏差观测、预测接口隔离、碰撞分类以及失败完成时间。另将4个选定用例的执行步长由0.02 s减为0.01 s：2个成功仍成功、2个碰撞仍碰撞；终止时刻差不超过0.02 s，最小间距差不超过约0.029 m。其中包括常温下的上述滚动策略失败；未对全部72例开展步长收敛检验。

初版采用浮点时间累加，导致恰好发生在12 s观测边界的速度变化可能延后一轮被读取。现改为整数步数生成时刻，并统一处理观测时间边界，加入回归测试。修复后的最终结果为22/24，修复前的20/24不作为结论。相关旧输出保留于 `results_crossing_uncertain/clock_boundary_diagnostic`，其中旧观测标签的输出位于 `obsolete_sensor_labels` 子目录；主结果以 `episodes.json` 中列出的72例为准，勿递归汇总诊断目录。

## 6. 当前限制与下一步车辆研究问题

风险预测沿参考轨迹加上当前固定的位姿偏差进行估计，尚未传播驱动转矩、制动力建立和跟踪误差的不确定性。执行端有这些动态，预测端仍较理想化。风险检查采用0.2 s离散采样、0.25 m阈值，没有连续时间碰撞保证。

横向路线固定；没有联合绕行优化。重规划参考将初始加速度/jerk设为零，实际控制请求受变化率限制，但没有证明重规划连接处的参考连续性和可执行性。紧急回退尚未验证安全，当前结果不能支持实车部署。

下一阶段值得检验的具体问题为：**在进入随时可能被占用的狭窄通行段之前，能否根据当前车速、实际驱动转矩、摩擦制动建立状态及观测延迟，限制车辆前进速度，使停车备选动作持续可执行？**

先比较“固定低速”“固定距离/时间裕量”“基于同一执行模型计算停车裕量”三种方案，保持同一场景、预测和执行模型，并明确失败条件。成功标准应同时包括接触、无进展、完成时间、停车位置和制动强度，不能只追求本批次零碰撞。随后才扩展场景和检索最接近的安全规划/备份控制研究；该问题本身尚不是已核实的创新点。

## 7. 复现与文件

在本文件所在bev目录依次执行：

```powershell
python -m unittest -v test_crossing_uncertain.py
python crossing_uncertain.py
python verify_crossing_uncertain.py
python plot_crossing_uncertain.py
```

需要numpy、matplotlib。实验写入 `results_crossing_uncertain`；开展新实验前另建结果目录或保存完整参数和代码快照。

- `episodes.json/csv`：最终72例汇总。
- `config_summary.json`：场景、观测、汇总结果和主模型哈希。
- `*_trace.csv`：实际车辆与横穿对象状态、碰撞、驱动/制动输出。
- `*_events.json`、`*_observations.json`：逐次决策与已收到的观测。
- `verification_failure_analysis.json`：独立验证、步长对照和失败诊断。
- `source_manifest.json`：本阶段代码及依赖模型SHA256。
- `pause_comparison.png`：道路中停顿对照。
- `retained_failure.png`：保留碰撞的状态与观测时间线。

本阶段未修改原始STV_ED实验包及上一轮二维场景结果。
