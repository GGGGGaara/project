## 当前状态 2026年11月3日 观测预测分离与滚动更新

最新完成：bev/crossing_uncertain.py将实际世界、延迟/偏差观测和恒速预测分开，接入前进模式中的0.5 s周期更新。详情见[观测预测分离与滚动更新验证记录](bev/观测预测分离与滚动更新验证记录.md)。

72个手工用例（4种运动×3种观测×2种车辆条件×3种策略）：frozen无碰撞完成8/24、refresh_hold完成10/24、rolling完成22/24。其余均碰撞终止，失败完整保留。不是现实事故概率，也不是原创或安全证明。

两次滚动策略失败均发生在较晚加速横穿、0.4 s观测延迟和负偏差组合中；12.5 s触发时车速约2.82 m/s，车头距横穿带边界约2.33 m，普通停车参考未找到，未验证制动回退仍于13.42 s接触。不能解释为物理不可避免，也不能单独归因于电动车再生制动。

6项单元测试通过，72条回放独立校验通过，4个选定用例检查执行步长减半。修复浮点计时导致边界观测延迟的问题，修复前输出归档于clock_boundary_diagnostic，不参与最终汇总。

下一项优先：检验进入狭窄通行段前，依据当前速度、驱动转矩、制动建立状态和观测延迟限制前进速度，是否能持续保留可执行停车动作。先与固定低速、固定距离/时间裕量进行同模型对照，再扩展场景和核查原创性。当前风险预测尚未传播实际执行器状态及不确定性。

## 前一阶段 二维横穿联调

最新完成：bev/crossing_2d.py把停车执行模块接入二维车辆，加入单个恒速横穿对象与路侧摊位。详情见[二维横穿场景联调记录](bev/二维横穿场景联调记录.md)。

本轮60次确定性执行（5个横穿时刻×3个车辆状态×4个内部策略）：nominal和slow_only各出现3次行人碰撞；stop_wait和candidate各15次均无碰撞完成。属于功能用例，不是真实交通碰撞率或方法创新证据。

二维转向、完整矩形车身碰撞、停车与再起步回放已经接通；横向路径固定，预测仍为脚本恒速世界中的完美预测。行驶段内尚不重新选择轨迹。4项单元测试和2项回放检查通过，另检查了4个用例的更小执行步长。

本轮入口与运行顺序，在bev目录执行：

```powershell
python -m unittest -v test_crossing_2d.py
python crossing_2d.py
python verify_crossing_2d.py
python plot_crossing_2d.py
```

结果目录：bev/results_crossing_2d，含参数、源代码哈希、60条结果、逐步轨迹、决策记录、图和局部GIF回放。

下一项优先：把实际世界与观测/预测分开，加入时刻或速度误差，并开展行驶中的周期性重规划。在这些基础上才比较固定时间裕量、状态相关时间包络与适当鲁棒空间基线。

## 前一阶段 低速停车v2

研究主线：纯电动乘用车在时变狭窄空间中的可执行运动规划。研究假设和创新性尚未确认，不能因使用电动车、MPC、时间窗或跟踪误差而直接宣称原创。

最新完成：低速纵向停车模块v2。详情见[停车模块改进与验证记录](bev/停车模块改进与验证记录.md)。

当前代码入口：bev/stopping_v2.py；验证：bev/verify_stopping_v2.py；图与参数快照：bev/plot_stopping_v2.py。

当前结果：bev/results_stopping_v2。48组输入中36组找到参考并完成两次停车，最大位置误差约7.3 mm；12组4 m/s、10 m停车距离输入未在指定参考族与约束下找到轨迹，保留在数据内。另一个4 m/s、15 m距离算例完成。以上为合成平路工况，不是实车精度。

验证：4项物理/积分/分类测试通过，已进行选定工况的步长与低速摩擦正则化敏感性检查。低速摩擦正则化为研究假设，参数未标定。

## 运行顺序

进入bev目录，依次运行：

```powershell
python stopping_v2.py
python verify_stopping_v2.py
python plot_stopping_v2.py
```

结果会写入results_stopping_v2。开展新的实验设计前，应使用新的结果目录或保存参数和源代码快照，避免不同模型的结果混用。

## 后续研究任务

1. 二维转向、矩形车体及单个横穿对象已在联调基准中实现，保持回归验证。
2. 预测/观测分离及前进模式周期更新已实现；优先诊断保留的制动失败，不先扩大场景复杂度。
3. 在同一BEV执行模型上比较固定低速、固定裕量、执行状态相关停车裕量；之后再比较时间占用包络及适当的鲁棒空间方法。
4. 判断时间占用表示是否在等价对照下有实际增量，再确定论文创新主张。
